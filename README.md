# Projetos Git

Mini projetos que desenvolvo enquanto estudo programação (CS50).

## Estrutura

- `C/`: projetos em C
- `JavaScript/`: projetos em JavaScript (Node.js)
- `Python/`: projetos em Python

## Como rodar

**C**
```bash
cd C/hello
clang -o hello hello.c -lcs50
./hello
```

**Python**
```bash
cd Python/hello
python3 hello.py
```

**JavaScript**
```bash
cd JavaScript/hello
node hello.js
```
